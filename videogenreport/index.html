AI 视频产品在中国大陆上线：成本和合规备忘录

这是一份给业务伙伴看的简版 memo。假设我们先做 V1：微信小程序或 Web 页面，用户输入想法，DeepSeek 做创意规划，可灵或 Seedance 负责生成视频。

版本：2026-05-16 用途：内部讨论 市场：中国大陆 非法律意见

项目判断

主要成本来自视频生成
约 ¥30-100+

用户做出一个满意的视频，通常会多生成几次，挑一个最好的版本。

文件播放成本比较可控
约 ¥0.5/GB

腾讯云 COS 中国大陆多地外网下行按量价为 ¥0.5/GB，早期可以先用对象存储。

合规需要提前设计
高优先级

尤其是 AI 标识、水印、人脸/声音授权、内容审核、个人信息保护。

价格提醒：AI 视频 API 的价格变化很快，而且“官网价、企业合同价、聚合 API 价格”可能完全不同。下面数字是为了讨论商业模型的 ballpark，不是采购报价。

成本概览

一个比较合理的 V1 架构是：一台云服务器负责账号、订单和任务状态；视频文件放对象存储；AI 视频生成直接调用可灵或 Seedance；DeepSeek 只负责把用户想法整理成镜头方案。

粗略单次成本怎么估

项目 保守估算 为什么这样估
DeepSeek 创意规划 约 ¥0.02-0.10 / 次 DeepSeek 中文官方价格页显示，V4 Pro 现价为输入缓存未命中 ¥3/百万 tokens、输出 ¥6/百万 tokens；缓存命中输入更低。一次规划假设 5,000 输入 + 2,000 输出，约 ¥0.015 + ¥0.012 = ¥0.027。留一点冗余，按几分钱到一毛钱估。
视频生成 API 约 ¥8 / 条 8 秒片段起 Seedance 2.0 的中文报道引用官方计费口径：不含视频输入 ¥46/百万 tokens，实测 15 秒约 30.888 万 tokens，约 ¥14.2，也就是接近 ¥1/秒。可灵的大陆官方 API 价格页没有找到可直接公开访问的 RMB 页面，建议后续以快手/可灵商务合同为准。
反复重试 乘以 2-5 倍 AI 视频经常需要抽卡。用户可能因为手、脸、镜头运动、品牌质感不满意而重试。
对象存储和带宽 按播放量计 腾讯云 COS 文档显示，北京、上海、广州、南京、成都、重庆等地域外网下行流量为 ¥0.5/GB。假设一个预览视频 20MB，播放 100 次约 2GB，也就是约 ¥1。
云服务器 约 ¥100-500 / 月起 V1 不在服务器上渲染视频，只做业务逻辑，所以一台普通云服务器即可。真正的压力在视频 API 和文件分发。

一个用户项目的例子

假设用户要做一个 20-30 秒的宣传短片，我们拆成 3 个 8 秒镜头。每个镜头平均生成 3 次才挑到满意版本。

计算步骤 估算
原始生成量 3 个镜头 × 3 次尝试 × 8 秒 = 72 秒生成量
视频 API 成本 按 Seedance 约 ¥1/秒口径，72 秒 × ¥1/秒 = 约 ¥72。若供应商合同价更低或更高，这里会相应变化。
DeepSeek 规划成本 约 ¥0.03-0.10，可忽略不计
存储和播放 早期通常 ¥1-5 以内，除非视频被大量分享
单个满意项目总成本 大约 ¥70-90 起，复杂项目或多次重试会更高

月度成本感受

场景 假设 大概成本
小范围内测 50 人，每人 1 个项目 约 ¥3,500-5,000 起，加上服务器和存储几百元
早期 beta 500 人，每人 1 个项目 约 ¥35,000-50,000 起，必须有积分或付费限制
正式推广 5,000 人，每人 1 个项目 约 ¥350,000-500,000 起，供应商合同和风控会变成核心问题

商业上最重要的一句话：不要按“用户最终下载了一个视频”收费，要按“每次生成尝试”消耗积分。否则用户反复抽卡，成本会被平台吃掉。

法律和合规风险

这个产品在中国大陆最大的风险不是技术，而是“生成了不该生成的东西”，或者“用了不该用的人脸、声音、品牌、素材”。V1 不需要做得很重，但底线要先搭起来。

风险 等级 业务上怎么理解 V1 建议
AI 生成内容标识 高 中国已经明确要求 AI 生成/合成内容需要标识。视频尤其敏感。 导出视频默认加“AI 生成”水印或标识，不提供去标识功能。页面和用户协议也写清楚。
人脸、声音、肖像 高 如果用户上传真人照片、做换脸、数字人、口型同步、声音克隆，会进入深度合成和个人敏感信息范围。 上传人脸/声音时必须确认“我有授权”。先屏蔿名人、公众人物、未成年人和政治人物。
违法和敏感内容 高 AI 视频可能被用于谣言、诈骗、色情、暴力、政治敏感内容、虚假新闻。 提示词、上传素材、生成结果都要审核。公开分享前再过一遍审核。
版权和品牌 中高 用户可能要求“做成某电影/某动漫/某明星/某品牌广告风格”。这容易碰版权、商标和肖像权。 先做黑名单：明星、影视 IP、知名品牌、平台 logo。条款里要求用户保证素材有权使用。
个人信息保护 高 手机号、微信账号、上传照片、生成历史、支付记录都可能是个人信息。 隐私政策、最小化收集、删除入口、保存期限、后台权限控制都要有。
数据跨境 中高 如果把中国用户的人脸、声音、图片或日志发到境外 API，会增加合规复杂度。 面向大陆用户时，优先选中国大陆可用的模型和云服务。跨境调用先做法律确认。
微信小程序审核 中 即使法律上可以做，平台也可能因为 AI 滥用、资质、内容安全或支付问题拒审。 准备用户协议、隐私政策、AI 标识截图、内容审核流程、客服入口和 ICP/备案材料。

V1 最低配置

  • 所有导出视频带 AI 标识或水印。
  • 用户上传人脸、声音、品牌素材时，需要勾选授权确认。
  • 提示词先审核，生成结果公开分享前再审核。
  • 限制高风险词：名人、公众人物、政治人物、色情、诈骗、新闻造假、知名 IP。
  • 每个生成任务记录用户、提示词、供应商、时间、输出链接，便于投诉和下架。
  • 先做封闭 beta，不要一上来开放公开广场或不受控分享。

我的建议：早期产品可以简单，但不要“裸奔”。最少要有 AI 标识、授权确认、内容审核、举报下架和日志记录。这些东西不只是合规，也是保护公司和合作伙伴。
